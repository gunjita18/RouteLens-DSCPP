# RouteLens-DSCPP
RouteLens: A graph-based multi-route visualization and optimization system using Dijkstra's algorithm, built in C/C++ with SFML.
RouteLens is a traffic route tracker that lets you see and compare routes between a start and finish at the same time unlike normal navigation apps such as Google Maps or Waze that show only one route at a time. RouteLens models the road system as a graph with intersections acting as vertices and roads acting as edges that carry weights based on travel time, distance and traffic level such as low, medium or high. To find the routes RouteLens uses Dijkstra’s algorithm together with core data structures such as adjacency lists, priority queues or min‑heaps linked lists and queues. RouteLens draws each route on the map in a color and shows a small information box that lists travel time, distance, traffic level and the number of traffic signals along that route; RouteLens highlights the fastest route in a bright color while the other routes stay visible so that you can compare them side by side. RouteLens simulates traffic by assigning medium or high conditions to each road, which changes the travel‑time weights and can shift the fastest route while you are driving. The main code, for RouteLens is written in C or C+ RouteLens shows how graph theory, shortest‑path algorithms and basic data structures can solve traffic problems in a clear and interactive way.
