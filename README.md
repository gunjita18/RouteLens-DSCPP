**RouteLens — Live-Traffic Multiple Routes Visualization and Optimization System**

RouteLens is a graph-based route planning and optimization system designed to help commuters visualize and compare multiple routes between a selected starting point and destination. Unlike conventional navigation systems that may emphasize a single recommended route, RouteLens displays up to three alternative routes together on an interactive map, allowing users to make more informed travel decisions. The system uses the real road network of Dehradun, extracted from OpenStreetMap (OSM) data, instead of relying on an imaginary map or simulated traffic conditions. Each route is displayed in a distinct colour with an information panel showing its estimated time of arrival (ETA), distance, number of traffic signals, and traffic level, categorized as Low, Medium, or High. The recommended route is highlighted based on the selected priorities, helping users understand why one route may be more suitable than another.
The core routing engine is developed in C++17 and represents the road network as a directed, weighted graph, where intersections are represented as vertices and roads as edges. Route calculation uses Dijkstra’s algorithm and A* search, supported by a custom-built binary min-heap. To generate meaningful alternatives, RouteLens also incorporates the penalty method and Yen’s k-shortest paths algorithm. Additional data structures and algorithms, including a KD-tree for nearest-road lookup, an LRU cache for route results, and forward and reverse breadth-first search that keeps the strongly connected part of the road network, support efficient road-network processing and route computation. Traffic speeds come from a TomTom Traffic Flow snapshot saved before the demo, so the application works offline and shows when the data was taken; free-flow travel-time estimates are used on roads without snapshot data. Users can adjust their preferences for travel time, distance, traffic signals, and congestion, making route selection more flexible and transparent. The project combines graph theory, shortest-path algorithms, data structures, real-world map data, and web technologies to develop a practical approach to multi-route visualization and traffic-aware route optimization.
Technology Stack: C++17, HTML, CSS, JavaScript, Leaflet.js, Chart.js, OpenStreetMap, OSMnx, Crow REST API, and TomTom Traffic Flow API.
